# 毛绒团培育小屋（maorongtuan-pet）

一只奶白毛绒团的长期养成小游戏：在 Muse 空间里运行的全栈应用，存档保存在服务端，可以长期养、每天有新鲜感。

## 玩法

- **五维照顾**：喂食、玩耍、洗澡、睡觉、贴贴，五种动作各有动画与粒子反馈；状态按真实时间消耗（单次结算封顶 24 小时）
- **五阶段进化**：幼团 → 小毛团 → 蓬蓬团 → 圆滚团 → 毛绒团长，每阶段解锁新能力与外观（呆毛、蝴蝶结、围巾、金星星）
- **口令本**：12 个可学习技能（转圈圈、打滚、击掌、顶球、唱歌……），每天有「新鲜招」，学会前可试演一次
- **后院探险**：花精力外出探险，收集 10 件收藏品、结识 6 位朋友
- **奇遇剧场**：5 部多幕分支剧情，结局可收集，进度可续玩
- **每日新鲜事**：每天自动采集一条真实新闻（动物/自然/太空/小科技），配上团团的新鲜招和回应
- **其他**：每日签到、小卖部、每日小脾气、三连招、连戳彩蛋、表情墙与配字台（可导出 720×880 表情包 PNG）

## 技术

- 前端：Three.js 手工 3D 团子（可拖拽旋转、连戳反馈），托管在 Muse 空间（Space）
- 后端：Space 全栈运行时，服务端持久化存档（等级 / 五维 / 毛绒币 / 背包 / 进化阶段 / 技能 / 收藏 / 日志）
- 本仓库是源码快照存档，由 Muse 经 GitHub 连接器增量推送；运行数据（app.db 等）不入库，见 `.gitignore`

## 说明

本仓库为个人项目的源码存档，运行时依赖 Muse 空间环境，克隆后不能直接独立运行。
